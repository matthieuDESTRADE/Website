Distance & speed estimation from car dashcam videos

A pipeline estimating the distance and relative speed of cars from dashcam videos, combining YOLO-based vehicle detection, vanishing point estimation, and license plate detection. Code available at GitHub.

This project was conducted in December 2023 for a computer vision course at École Polytechnique, in collaboration with Pierre-Emmanuel Bavière.

About this project Read report Access code

Autonomous vehicles typically rely on radar or LiDAR to estimate distances to surrounding objects. We explored whether a single traditional dashcam, placed in an arbitrary but roughly road-aligned position, could provide a similar estimate on its own. Our approach relies on three stages: detecting vehicles in the video with YOLO, locating the road's vanishing point, and calibrating absolute distances through license plate detection.

The vanishing point is estimated by extracting road and building lines with OpenCV's Hough transform, then robustly finding their common intersection with a RANSAC procedure that discards non-converging outlier lines (traffic signs, tree branches, other vehicles). This vanishing point, combined with a single reference distance, is enough to convert a vehicle's vertical position in the frame into a real-world distance along the camera's view axis.

To obtain that reference distance, we detect license plates with a YOLO model fine-tuned for this task, then refine their contours with OpenCV to recover their pixel width. Since real license plates have a known, standardized size, this gives an absolute distance estimate for any vehicle whose plate is visible. Averaging and outlier rejection across frames stabilize the resulting distance and speed estimates on video.

Reinforcement Learning with a driving game

An agent trained end-to-end from raw pixels to learn to steer a car on a custom 2D driving game with randomly generated track, using deep Q-learning. Code available at GitHub.

This project was conducted in March 2024 for an autonomous agents course at École Polytechnique, in collaboration with Pierre-Emmanuel Bavière, Hugo Aoyagi, and Raphaël Manus.

About this project Read report Access code

We built a simple driving game in which a car must stay on a randomly generated road, wrapped it as a gymnasium environment, and trained agents to play it using only the same visual information a human player would have: a downsized, color-simplified 40x40 frame. This pushed us toward deep convolutional Q-learning to extract useful features directly from pixels.

Our deep Q-network combines a replay buffer and a target network to stabilize training, following the classic DQN recipe. We found that frame-skipping, applying each chosen action over several frames, was key to early training, and progressively fine-tuning a model from a large frame-skip down to a single frame produced by far our most stable and efficient agent.

We also probed the trained convolutional filters through activation maximization, and found channels that had specifically learned to respond to the car's colors and to the road's edges.

3D reconstruction of Church at Auvers-sur-Oise

An OpenGL scene bringing Van Gogh's painting to life in 3D, using a cloth-like physical simulation to animate the sky, ground, and grass along with a hierarchically animated character. Code available at GitHub.

This project was conducted in June 2023 for a computer graphics course at École Polytechnique, in collaboration with Julien Genzling.

About this project Read report Access code

We set out to recreate Van Gogh's Church at Auvers-sur-Oise as a 3D scene, capturing the sense of motion that define the original painting. The scene is framed inside a unit cube, rendered as a "3D painting" using stencil and depth buffers so that elements are only visible through the frame, while still letting the camera move inside it.

The sky, ground, and grass are all composed of numerous 2D meshes driven by a cloth-like physical model, animated by noise. The path flows like a stream along a spline built from a handful of control points.

The church and houses were modelled in Blender and hand-painted in Procreate, then given a dedicated shader that applies a time-dependent deformation for a "twisted" look. The church's shadow is reproduced in the grass and path by recoloring fragments inside an affine region. The woman is animated as a layered character: a forward-kinematics mesh hierarchy following the path, dressed in a simulated cylindrical cloth skirt kept from clipping through the legs by a repulsive potential.

PACE challenge 2024

Heuristics for the one-sided crossing minimization problem, using median-based and greedy insertion algorithms. Code available at GitHub.

This project was conducted in March 2024 for an algorithmic geometry course at École Polytechnique, in collaboration with Thomas Dagonneau.

About this project Read report Access code

We tackled the PACE 2024 challenge on minimizing edge crossings in a two-layered drawing of a bipartite graph, an NP-complete problem. After building tools to generate random graphs and compute exact solutions by brute force on small instances, we designed a fast median-based heuristic and a more precise greedy algorithm that inserts vertices one by one at their locally optimal position. The greedy method consistently outperformed the median heuristic, at a higher but still practical computational cost.

French news title generation

A Kaggle challenge on generating titles for French press articles, which involved comparing pretrained French summarization models, text-reduction strategies, and fine-tuning to maximize ROUGE-L scores. Code available at GitHub.

This project was conducted in March 2024 for an NLP course at École Polytechnique, in collaboration with Charles-Edouard Rouault.

About this project Read report Access code

The challenge consisted in generating the title of French press articles from their texts, scored against the real title with the ROUGE-L F1-score. After analyzing the dataset, we found it too small to train a model from scratch, which pointed us toward fine-tuning existing French summarization models such as BARThez and CamemBERT2CamemBERT.

We benchmarked several pretrained French summarization models and tackled their limited input length with text-reduction strategies: splitting and re-concatenating summaries, and an extractive preprocessing step based on sentence-similarity, both promising on individual examples but not on the dataset as a whole.

Fine-tuning proved the most effective lever. We discovered that our best baseline model, barthez-orangesum-abstract, had in fact already been trained on the challenge's underlying dataset, leaving little room for improvement, while fine-tuning camembert2camembert-shared-finetuned-french-summarization on our training set noticeably improved its ROUGE-L score.

French cities facing large language models

A qualitative study, based on seventeen interviews with French cities and intermunicipal bodies, on how large language models are being deployed in local public administrations and the organizational tensions this raises.

This project was conducted during the 2025-2026 academic year for the PAPDD master, in collaboration with Tigrane Boccara Kebadian, Ségolène Grouale, and Mohammed-Yassine Habibi, supervised by professor Gilles Jeannot (LATTS, ENPC).

About this project Read report (French)

We combined an analytical questionnaire with semi-structured interviews targeting both general services directors and IT directors across 17 local authorities (12 metropolitan areas, 5 smaller cities or intermunicipal bodies) already engaged with AI, to understand how LLM tools were being governed within their organizations.

We found that LLM tools have spread to every city surveyed, mostly through a "wait-and-see continuity" around Microsoft Copilot, a "cautious curiosity" toward sovereign French tools such as Délibia, or more exploratory experimentation, while usage itself remains largely confined to an "augmented agent" model: assisting with drafting, research, or verification under systematic human supervision, rather than autonomous decision-making or direct interaction with citizens.

This organizational continuity, however, leaves several emerging risks under-addressed: data security and sovereignty, uneven impacts on public-sector jobs, and an environmental footprint that remains largely unmeasured. We argue that a genuine organizational shift is needed, and propose a set of recommendations covering risk-controlled innovation, pre-deployment strategic evaluation, transversal internal governance, and inter-municipal cooperation to pool resources and reduce dependence on private providers.
