SUREdiff

Uncertainty estimation and OOD detection with deep learning diffusion models and a new method based on Stein's unbiased risk estimate (SURE). Applications to MRI data and BMC estimation.

This work was conducted from May 2024 to August 2024 during a four-month research internship at the Nara Institute of Science and Technology (NAIST) and CentraleSupélec, under the supervision of professors Hugues talbot and Yoshito Otake.

About this project Read report

In a number of fields, such as medicine or autonomous driving, the estimation of the uncertainty of the results of deep learning algorithms is a fundamental task to prevent harmful errors. In this internship, we aimed at evaluating medical images generated with diffusion models, and more specifically image translation. We wished to be able to detect defects in the generated image as well as in the input image based on the generation uncertainty.

To do so, we proposed a lightweight uncertainty estimation method based on the SURE estimator that is applicable to any pretrained diffusion network: SUREdiff.

In order to test the initial performance of SUREdiff, we performed several out-of-the-distribution (OOD) detection tasks inspired by a reconstruction-based approach, but where uncertainty estimation is used rather than reconstruction error. On these tasks, we obtained very promising performances.

We then focused on applying SUREdiff to image translation models and evaluating the correlation between predicted uncertainties and errors of medical measures performed using the generated images. On such tasks, we compared it with other uncertainty estimation methods. We found that SUREdiff accurately predicts the expected generation error and outperforms existing approaches such as MC Dropout and BayesDiff. However, this capability alone is not sufficient to reliably detect failures in the medical measurement estimation task.

Planning with World Models

Leveraging value function learning and hierarchical architectures to improve Joint-Embedded Predictive Architectures (JEPA) planning capabilities. Led to a paper and a poster presentation at WMW2026.

This work was conducted from April 2025 to August 2025 during a five-month research internship at the Courant Institue (NYU), under the supervision of professors Yann LeCun and Jean Ponce.

About this project Read report

In order to obtain a deep learning model capable of “reasoning,” it appears necessary to train a world model, that is, a model that captures the laws governing the evolution of a dynamical system. Joint-Embedded Predictive Architectures (JEPA) provide one way of implementing such models. They learn representations of the world along with a predictor, using prediction loss as the training criterion. Beyond providing access to meaningful representations of an environment’s states, these models also enable action planning, which is the task of optimizing a sequence of actions to reach a goal from a given initial state.

In this study, we proposed two approaches to improve the action planning capabilities of JEPA world models. The first consists in learning representations such that the distance between two state representations reflects the goal-conditioned value function associated with a reaching cost. We described a method to achieve this and implement it, obtaining better planning performance than traditional JEPA models on simple planning tasks.

The second approach is to use a hierarchy of representations to better capture relationships between distant states and to increase the prediction horizon. Although we did not obtain good results with this method, we highlighted an issue that arises when performing action planning with a JEPA model: optimizing action representations often yields unrealistic solutions on which the predictor is unreliable. To address this issue, we proposed regularizing the action representation space. However, this did not lead to improved planning results on our tasks.

Hierarchical LLM

Investigating hierarchical architectures as a means to improve the computational efficiency and abstraction capabilities of LLMs. Code available at GitHub.

This work was conducted in March 2025 for a LLM course of the master MVA.

About this project Access codeRead slides


We investigated hierarchical representations for improving the abstraction and long-range reasoning capabilities of language models. The approach combines token-level autoregressive prediction with higher-level latent representations that summarize longer sequences and provide additional predictive context. Inspired by JEPA architectures, the model explores whether learned abstractions can complement traditional next-token prediction. Initial experiments on small-scale datasets show modest improvements over a standard GPT-style baseline, opening avenues for scaling hierarchical language modeling.

Neural 3D Reconstruction

Extending RayGauss, a Gaussian-based rendering framework for novel view synthesis, with physically-inspired rendering improvements (new basis functions and translucent-aware color blending). Code available at GitHub.

This work was conducted in March 2025 for a 3D point clouds course of the master MVA, in collaboration with Nour Rizk.

About this project Read reportAccess code


This project explored photorealistic novel view synthesis, a key problem in computer vision and computer graphics that aims to generate unseen viewpoints of a 3D scene from a limited set of images. We studied and implement RayGauss, a recent approach combining the flexibility of Gaussian-based scene representations with the physical accuracy of volumetric ray casting, overcoming limitations of methods such as Neural Radiance Fields (NeRF) and 3D Gaussian Splatting.

Beyond reproducing the original method, we investigated improvements to the rendering pipeline by introducing new view-dependent basis functions inspired by classical Phong illumination models and a modified color blending strategy designed to better handle translucent materials. These extensions aimed to improve the physical consistency of light transport and enhance the representation of complex visual effects.

Experiments on the Blender dataset showed that our modifications can slightly improve reconstruction quality, demonstrating their potential. Larger-scale experiments could further validate their effectiveness.

Missing Data imputation

Extension of NOT-MIWAE, a deep generative model designed for Missing Not At Random data imputation, using an additional latent variable to better model complex missingness mechanisms. Code available at GitHub.

This project was conducted in December 2024 for a probabilistic graphical model course of the master MVA, in collaboration with Félix Houdouin.

About this project Read report Access code

Handling missing data is a fundamental challenge in statistical learning, particularly when the missingness mechanism deviates from standard assumptions such as Missing Completely At Random (MCAR) or Missing At Random (MAR). In this project, we studied the NOT-MIWAE framework, a deep generative approach designed to address the more general and realistic Missing Not At Random (MNAR) setting. The model uses a variational inference approach to reconstruct missing values while explicitly modeling the probability of observing each feature.

We proposed an extension introducing an additional latent variable dedicated to the missingness process. This modification aims at relaxing the independence assumptions made by the original model and improving performance in more complex MNAR settings.

Experiments were conducted on a modified UCI white wine dataset with synthetic MNAR missingness patterns. The proposed extension improved reconstruction performance compared with standard NOT-MIWAE variants in settings where the original assumptions were violated.
